# 线下展览活动预约报名 Demo

React + TypeScript + Tailwind CSS 前端 Demo，模拟松赞小程序内的会员活动预约、个人中心、现场扫码签到，以及 B 端运营后台配置和报名管理。

## 功能

- C 端小程序模拟：活动预约 Demo 页、小程序个人中心、我的预约、现场扫码签到
- B 端运营后台：活动配置、预约规则、场次管理、报名名单、数据看板
- 本地 mock 状态：登录态、库存扣减/释放、预约码、签到数据、后台核销

## 本地运行

```bash
npm install
npm run dev
```

## 构建

```bash
npm run build
```
